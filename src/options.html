Stackslop

Copy GitHub pull requests with their title and diff stat, one at a time or as a stack.

Needed for private repos. Run gh auth token | pbcopy and paste the result. It stays in this browser.

Links point to

Linear links come from the “Review in Linear” comment on each PR, or from Linear when you’re signed in to it in this browser. PRs Linear hasn’t reviewed keep their GitHub link.

View in Linear tab

Adds a tab after Files changed on PRs with a Linear review in a workspace you’re signed in to.
